


# Hi, I’m Ioan 👋

I’m a backend-focused developer based in Norway.

I build web applications and internal business tools using TypeScript, Node.js, NestJS, C#/.NET and PostgreSQL. Most of my projects involve APIs, authentication and authorization, multi-tenant data, document workflows, integrations and operational business logic.

I’m particularly interested in software that reduces manual work and makes existing processes easier to understand, manage and improve.

Some of my portfolio projects explore Norwegian public-sector and industry use cases, including municipal case handling, technical service workflows, document security and data-driven tools for water and wastewater operations.

My approach is practical: clear architecture, reliable data models, automated testing, security and honest documentation about what is implemented and what would still be required for production.

### Main technologies

`TypeScript` · `Node.js` · `NestJS` · `C# / .NET` · `PostgreSQL` · `Next.js` · `Docker` · `GitHub Actions`

### Selected projects

* **WorkFlow Hub** — workflow automation and integrations for Norwegian technical service companies.
* **KommuneFlow AI** — multi-tenant municipal case handling with document workflows, audit logs and human-reviewed AI assistance.
* **TrustVault Lite** — secure B2B document portal focused on authorization, tenant isolation and auditability.
* **VA Drift Insight** — backend and data tools for water and wastewater operations, combining my software work with practical VVS/VA experience.

I’m currently continuing to strengthen my backend, cloud and system integration experience.
